# Recursos visuales

La versión actual crea el logotipo directamente con widgets Flutter e iconos
Material. Esta carpeta queda preparada para incorporar más adelante:

- Logotipo institucional.
- Fotografías del prototipo físico.
- Ilustraciones del tramo vial.
- Tipografía institucional con licencia adecuada.

Si se agregan archivos, deben declararse en la sección `flutter/assets` de
`pubspec.yaml`.
